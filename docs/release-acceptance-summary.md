# AIRoot 0.1.1 Preview 验收摘要

核对日期：2026-10-28。此文件是脱敏摘要，不含原始 Harness 对话、凭据、虚拟机账户信息或机器专属路径。历史结果只有在产品文件指纹一致时才适用于对应构建。

## 已验证

- Rust 全量测试：148 passed、0 failed、1 ignored；格式检查与 Clippy 通过。
- DeepSeek Harness 插件 Node 测试通过。
- 当前候选构建的可靠性、登记保护、扫描和离线安装包私有/原生索引生命周期已有本机测试记录。
- 最终 EXE 的 Harness 联调最近两轮共 9 个有效场景、77 次工具调用通过。受限模式场景因当轮未加载 AIRoot SKILL，不计为通过。
- 测试 VM 已恢复到干净检查点；临时 Harness 中继已停止，来宾测试凭据与测试数据已清除。

上述结果不证明真人审批界面效果，也不构成对恶意 Agent 的普遍防护保证。模拟或构造的恢复现场不算作真实操作系统崩溃测试。

## 首版发布阻断

- 真实 Python 与 Miniforge 安装器未产生 `3010` 重启返回码，因此供应商跨重启场景未执行；模拟结果不能替代。
- 当前 SKILL 修订在干净 Windows 系统上的 bootstrap 尚未完成。
- Harness 受限模式用例需在加载当前 AIRoot SKILL 后重新运行。
- Microsoft Visual C++ app-local runtime 的公开再分发资格尚待发布者核实。源代码保留了对应来源和许可通知，但这不等于已取得或确认再分发资格。

因此本版本继续标记为 `0.1.1 preview`。完整首版认证及公开安装包发布条件尚未满足；此摘要不授权发布安装包。第三方服务凭据是否已在服务商侧撤销，无法由本机验证；使用过临时测试凭据的人员应在服务商控制台完成撤销。
