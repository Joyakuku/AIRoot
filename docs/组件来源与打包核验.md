# 组件来源与打包核验

核验日期：2026-10-19。发行目标：Windows x64。本页记录当前锁定构建，不代表这些版本是最新版本。

精确 URL、压缩包 SHA256、包内成员、可执行文件 SHA256 均存于 `packaging/components.lock.json`。没有采用机器上已有 Everything；没有包含 Pylance 或整套 VS Code 扩展。

已读取随源文件中的许可条件；本包保持版权、许可和第三方通知。Everything/es 的声明包含再分发许可及保留声明要求，fd/PET 对应许可和第三方声明随程序保留，不删改为 AIRoot 自有版权。AIRoot 自有代码采用 MIT，版权归 Joyakuku；该许可不覆盖第三方组件。Microsoft app-local Visual C++ runtime 的适用再分发资格仍须由发布者确认，因此在确认前不发布包含该二进制的安装包。

## 可重复检查

1. `scripts/fetch-components.ps1` 从锁定来源获取并核对压缩包和二进制。
2. `scripts/component_notices.py` 从匹配的 fd v10.5.0 与 PET 2024.16.0 源码锁文件收集 Windows normal/build 依赖声明，分别记录 61、70 个依赖包。另保存原始 Microsoft Python ThirdPartyNotices 文件。
3. `packaging/notices.lock.json` 保存声明文件的完整清单及 SHA256；打包逐项检查，缺失、改动或未登记的声明文件均使构建失败。
4. `scripts/package_payload.py` 从 AIRoot 的 Cargo.lock 解析实际运行/构建依赖，收集各包声明、SQLite 公有领域声明和 Rust 标准库版权/许可。缺少声明时构建失败。
5. 安装包内 `package-manifest.json` 覆盖全部 payload 文件及哈希；安装、升级、卸载均检查归属，不覆盖用户新增或修改文件。

## 2026-10-28：PET 干净系统运行依赖

干净 Windows VM 实测 PET 缺少 VCRUNTIME140.dll，退出 -1073741515。新增 Microsoft 签名的 app-local release runtime 14.29.30157.0，来自本机 Visual Studio 2019 的 x64 VC/Redist 目录，锁定哈希并保留来源/再分发条件，不安装宿主机全局组件。PET 查询与执行前同时校验该依赖，打包还实际执行 --version，不再只验哈希。

重新获取时通过 `scripts/fetch-components.ps1 -VCRuntimeSource <已获许可的原始 VS release redist DLL>` 提供固定原件；拒绝 System32、未知 DLL 来源、签名或哈希不符。不声称验证了用户许可资格；对外发布仍需项目所有者核对适用许可。本地评估预览不等于公开发布授权。
